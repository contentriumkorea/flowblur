VeloBlur 0.3.2

- Premiere 효과 목록과 업데이트 창의 표시 이름을 VeloBlur Motion Blur로 변경했습니다.
- 기존 프로젝트의 효과 식별자와 설치·업데이트 경로는 유지합니다.

- Premiere Pro 전용 폴더에 설치하여 After Effects에서 표시되지 않습니다.
- 백업을 플러그인으로 다시 읽던 중복 로딩 문제를 수정했습니다.

- 효과 컨트롤에서 Update > Check for Updates를 눌러 새 버전을 확인합니다.
- 다운로드 후 Adobe 앱을 종료하고 설치할 수 있습니다.
- 업데이트 파일의 서명과 해시를 검증합니다.
- 설치 실패 시 이전 파일을 복원하고 기존 활성화 정보를 유지합니다.
- Windows x64용 CPU 모션블러 프로토타입입니다.
